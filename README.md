# teocs

My solutions to the projects from **_The Elements of Computing Systems_**
(2nd edition) by Noam Nisan and Shimon Schocken, also known as
[Nand2Tetris](https://www.nand2tetris.org). The book builds a computer from
the ground up, from logic gates to an operating system.

Instead of the book's HDL and tools, I'm doing the projects in C, to practice
the language while learning how a computer works.
